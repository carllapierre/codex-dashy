# Codex Dashy documentation

Codex Dashy is intentionally small, but its documentation follows the same boundaries as the codebase:

- [Stack](stack.md) — runtimes, dependencies, local development, and Docker.
- [Architecture](architecture.md) — the bridge, API, frontend, persistence, and data flow.
- [Telemetry](telemetry.md) — OTEL configuration, stored data, usage limits, and estimated cost.
- [Testing](testing.md) — quality checks, test scope, and verification commands.

Contributor conventions and separation-of-concerns rules live in [AGENTS.md](../AGENTS.md).
